# 日本 車輛拍賣 —— 兩個 Demo

依這兩份規格製作的純前端 Demo（無後端、假資料存 localStorage）：

- 《日本-車輛拍賣-內部系統（車輛管理／拍賣管理）》 **V3.6**（`japan-knowledge/PM/docs/specs/active/2026-08-26-internal-auction-module.md`）
- 《日本-車輛拍賣-廠商競價站》 **V3.5**（`japan-knowledge/PM/docs/specs/active/2026-08-26-dealer-bidding-site.md`）

**兩站的畫面直接取自正式專案**，只把 API 層換成瀏覽器內的假後端：

| Demo | 畫面來源 | 換掉的部分 |
|---|---|---|
| 內部系統 | `xstar-web-pc/application/auction-management/src` → `src/internal/`（workspace packages 放在 `src/internal/vendor/packages/`） | `$axios` 改走 `src/internal/mock/`；外面套一層 portal 側欄／頂部列與 Demo 權限切換 |
| 對外系統 | `auction-platform/src` → `src/dealer/` | `src/dealer/mock/` 改為呼叫共用拍賣核心；倒數改用 Demo 的伺服器時間；登入頁加 Demo 帳號 |

要同步正式專案的新改動：把對應檔案重新複製過來即可，兩邊的 `@/` import 由 `vite.config.js` 依檔案所在資料夾自動對應，不必改寫。

## 啟動

```bash
cd demo
npm install
npm run dev
```

開 <http://localhost:5180/> 會看到入口頁，兩個 Demo 各自一個網址：

| Demo | 網址 |
|---|---|
| 內部系統（車輛拍賣） | <http://localhost:5180/internal.html> |
| 對外系統（XSTAR BIDDING） | <http://localhost:5180/dealer.html> |

`npm run build` / `npm run preview` 也可用（三個 entry 各自打包）。

## 兩站是分開的，但共用同一份假資料

規格上兩站是**獨立專案、獨立部署，後端拍賣核心與資料共用**。這裡用同一個 Vite 專案的兩個
entry 模擬：`src/shared/engine.js` 扮演後端拍賣核心，兩個前端的 mock adapter 把正式 API 路徑對應到它。
兩站在同一個 origin，共用 localStorage，並透過 `BroadcastChannel` 即時同步。

**把兩個分頁並排開著，就能走完整條流程：**

```
內部：Demo 控制台 →「呼叫收車通知」（貸後端介接）
        ↓
內部：車輛管理 → 填走行距離 → 勾選多台 →「排定拍賣」（整批共用一組起訖日）
        ├─ 開始日＝今日：直接進「拍賣進行中」，對外站立刻出現 + 一封含本批清單的上架通知
        └─ 開始日＞今日：進「待開始」（可「取消排定」）；快轉到開始日 00:00 才上架、09:00 發通知
        ↓
對外：拍賣列表 → 入札する（卡片彈窗或詳細頁）／取り消す
        ↓（內部的「已出價家數」+1／取消則 -1，並重新納入催投對象）
內部：快轉到截止 → 已結標 → 詳細 → 指定成交廠商／進入加價拍賣
        ↓（呼叫貸後的成交通知，成功才轉入已決標）
對外：已得標 ＋ お知らせ（得標／未得標）
        ↓
內部：Demo 控制台 →「呼叫結清通知」→ 該筆自已決標軟刪除，對外站也不再顯示
```

資料鍵值為 `jp-auction-demo/v3`，跨日自動重建（seed 日期皆相對今天）。重置方式：任一站的 Demo 控制台 →「重置 Demo 資料」，
或 Console 執行 `localStorage.clear()` 後重新整理。

## Demo 控制台

拍賣時間精度到「日」（開始＝開始日 00:00、截止＝結束日 23:59:59 JST），要看自動行為必須快轉時間。

| 功能 | 說明 |
|---|---|
| 時間快轉 | +1 小時 / +6 小時 / +1 天。偏移量存在共用資料裡，兩站同步 |
| 回到現在時間 | 清掉偏移 |
| **呼叫收車通知**（內部站） | 代替貸後團隊帶 orderNo ＋ 收車日呼叫。車輛資料由本模組依 orderNo 自行取得、附件不帶入。重複呼叫冪等 |
| **呼叫結清通知**（內部站） | 選一筆已決標的 orderNo 呼叫，該筆以軟刪除自「已決標」移除。重複呼叫冪等 |
| **讓成交通知失敗**（內部站） | 開啟後指定成交時對貸後的成交通知會失敗 → 訂單留在「已結標」、得標／未得標通知一律不發，可重試 |
| **帳號通知（僅 Email）**（內部站） | 新增廠商與重設密碼寄出的兩封信（規格 8.1 文案）；這兩類不進站內通知 |
| 重置 Demo 資料 | 回到初始 seed |
| 切換廠商（對外站） | 不用重新登入就能換成別家廠商的視角 |
| 開啟另一站 | 開新分頁 |

快轉之後會自動發生：**開始**（待開始 → 拍賣進行中，開始日 00:00）、**開始日通知**（09:00，上架通知依批次歸組）、
**自動催投**（結標日前 2 天 09:00，須晚於開始日）、**結標**（進行中 → 已結標）。

## 帳號

**內部系統**不做登入，右上角有 Demo 用的角色切換（規格第三章，一個帳號可同時擁有兩者）：

| 角色 | 權限點 | 看得到什麼 |
|---|---|---|
| 催收人員 | 六個全有 | 四個 tab 全部可見且功能完整（取消排定、催投、出價紀錄、指定成交、加價輪） |
| 財務人員 | 無 | 「待開始」「拍賣進行中」「已決標」**唯讀**；「已結標」tab 不呈現；已決標無「操作」欄 |

只勾「財務人員」時：「已結標」tab **直接消失**（不是 disable）、待開始無「取消排定」、進行中無「催投」、已決標整欄無「操作」。
車輛管理與廠商管理兩個角色完全相同。

**對外系統**用 Email + 密碼登入，登入頁下方有一鍵帶入的 Demo 帳號（seed 帳號密碼一律 `demo1234`）：

| 廠商 | Email | 狀態 |
|---|---|---|
| 山田商事株式会社 | yamada@example.co.jp | 啟用（**建議用這家看 Demo**） |
| 鈴木自動車販売 | suzuki@example.co.jp | 啟用 |
| 田中モータース | tanaka@example.co.jp | 啟用 |
| 佐藤オートセールス | sato@example.co.jp | 啟用（看不到レクサス RX 的加價輪） |
| 高橋カーズ | takahashi@example.co.jp | **停用 → 無法登入** |
| 伊藤モーターサービス | ito@example.co.jp | **鎖定中 → 無法登入**，須內部「解鎖」 |

站上**沒有忘記密碼、也沒有修改密碼**。連續輸錯 5 次鎖定（不自動解鎖），只能由內部「解鎖」；忘記密碼由內部「重設密碼」重發至登入 Email。

| 車輛 | 狀態 | 用來看什麼 |

| （Demo 控制台）トヨタ ヴォクシー／ホンダ N-BOX | 未收車 | 呼叫「收車通知」後才出現在車輛管理，附件為空 |
| トヨタ ノア／ホンダ ステップワゴン | **待開始**・首輪 | 同一批次、後天開始；可「取消排定」其中一台，開始日的上架通知只列剩下那台 |
| トヨタ ルーミー | **待開始**・首輪 | 5 天後開始，另一個批次 |

| トヨタ アルファード／ダイハツ タント | 進行中・首輪 | 同一批次、昨天開始（新着出品）。アルファード 3 家已出價；タント無人出價、**零附件 → 對外卡片示意圖＋詳細頁「尚無照片」** |

| 三菱 デリカ D:5 | 已結標 | **無人出價 → 指定成交 disable**，只能進入加價拍賣 |
| スズキ スイフト | 已結標 | **出價的廠商皆已停用 → 指定成交 disable** |

## 專案結構

```
demo/
├── index.html          入口頁
├── internal.html       內部系統 entry
├── dealer.html         對外系統 entry
├── vite.config.js      依檔案所在資料夾解析 `@/`（內部 → src/internal、對外 → src/dealer）
└── src/
    ├── shared/         兩站共用的「後端」
    │   ├── constants.js  車輛欄位、狀態、權限點、廠牌主檔
    │   ├── seed.js       假資料
    │   ├── store.js      localStorage 持久化 + 跨分頁同步 + 伺服器時間（含 Demo 偏移）
    │   ├── engine.js     拍賣核心：排定／待開始／取消排定／出價／放棄出價／結標／指定成交／
    │   │                 加價輪／催投／通知、對外站登入與帳號鎖定、貸後三支介接 API
    │   ├── noticeText.js 站內通知標題與內文（日文）
    │   ├── photos.js     車輛照片（SVG data URI 產生，完全離線）
    │   └── format.js
    ├── internal/       ← xstar-web-pc auction-management（Vue 3 + Element Plus + vue-i18n zh/ja）
    │   ├── mock/         正式 API 路徑 → engine
    │   └── vendor/       @packages/*（x-components、x-axios、utils、theme）
    └── dealer/         ← auction-platform（Vue 3 + Element Plus + Tailwind v4 + vue-i18n ja）
        └── mock/         正式 API 路徑 → engine
```
