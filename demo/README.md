# 日本 車輛拍賣 —— 兩個 Demo

依這兩份規格製作的純前端 Demo（無後端、假資料存 localStorage）：

- 《日本-車輛拍賣-內部系統（車輛管理／拍賣管理）》 **V1.4**
- 《日本-車輛拍賣-廠商競價站》 **V1.4**

技術參考《車輛拍賣 —— 既有 portal 實作參考筆記》。

---

## 啟動

```bash
cd demo
npm install
npm run dev
```

開 <http://localhost:5180/> 會看到入口頁，兩個 Demo 各自一個網址：

| Demo | 網址 |
|---|---|
| 內部系統（車両オークション管理） | <http://localhost:5180/internal.html> |
| 對外系統（廠商競價站） | <http://localhost:5180/dealer.html> |

`npm run build` / `npm run preview` 也可用（三個 entry 各自打包）。

---

## 兩站是分開的，但共用同一份假資料

規格上兩站是**獨立專案、獨立部署，後端拍賣核心與資料共用**。這裡用同一個 Vite 專案的兩個
entry 來模擬：兩站在同一個 origin，因此共用 localStorage，並透過 `BroadcastChannel` 即時同步。

**把兩個分頁並排開著，就能走完整條流程：**

```
內部：車輛管理 → 排定拍賣
        ↓（對外站立刻出現這台車 + 通知）
對外：出品一覧 → 車両詳細 → 入札
        ↓（內部的「已出價家數」立刻 +1）
內部：拍賣管理 → 已結標 → 決標／指定成交／加價輪
        ↓
對外：落札済み ＋ お知らせ（得標／未得標）
```

資料鍵值為 `jp-auction-demo/v1`。重置方式：任一站右下角的 Demo 控制台 →「重置 Demo 資料」，
或 Console 執行 `localStorage.clear()` 後重新整理。

## Demo 控制台（右下角浮動）

因為拍賣時間精度到「日」（截止＝結束日 23:59:59 JST），要看截止行為必須快轉時間。

| 功能 | 說明 |
|---|---|
| 時間快轉 | +1 小時 / +6 小時 / +1 天。偏移量存在共用資料裡，兩站同步 |
| 回到現在時間 | 清掉偏移 |
| 重置 Demo 資料 | 回到初始 seed |
| 切換廠商（對外站） | 不用重新登入就能換成別家廠商的視角 |
| 開啟另一站 | 開新分頁 |

快轉之後會自動發生：**結標**（進行中 → 已結標）與**自動催投**（結標日前 2 天 09:00 JST，
對該輪尚未出價的廠商發一次）。

## 內部系統

樣式對齊 `xstar-web-pc`：**沒有搬任何 component 過來，只照著版型與樣式重寫。**

| 慣例 | 來源 |
|---|---|
| 側欄 108px `#2c2c37` ＋ hover 展開子選單、頂部 60px 白底 header | `system-base-vue` 的 `layout/LeftMenu.vue`、`TopHeader.vue` |
| `.page-wrap` 背景 `#f7f8fa`、padding 16/20；`.tab-filter-section`、`.table-section` 白底 radius 16px | `credit-approve/src/common/styles/custom.scss` |
| el-table 表頭 `#F8F8F8`、首尾格 radius 8px、無底線；分頁靠右 margin-top 36px、按鈕 radius 8px | `common/styles/element.scss` |
| 篩選區 `label-position="top"`、`el-row :gutter="32"`、`el-col :span="6"`（一列 4 欄） | `@packages/x-components/xFilterForm.vue` |
| 詳細彈窗的資料區塊「值在上、灰色 label 在下」的網格 | `@packages/x-components/xInfoCard.vue` |
| 主色 `#0568FF` ＋ light-1〜9 的生成演算法 | `@packages/theme/index.js`、`settings.js` |
| 操作欄寬度依語言調整（`locale === 'ja' ? 230 : 190`） | 實作筆記 §2 |
| 介面中／日雙語（vue-i18n） | 規格第八章「內部 portal 為中文、日文」 |

### 涵蓋的功能

- **車輛管理**：列表（篩選／分頁／預設收車日近到遠）、車輛詳細彈窗（全欄位＋就地更新
  走行距離・次回車検日・自賠責保険の有効期限・備考、更新紀錄留存前後值與操作人）、
  附件（白名單分類，可上傳／刪除本模組附件）、排定拍賣（前置檢核 → 日期 → 二次確認唯讀）
- **拍賣管理**：三個 tab、即時倒數、到期自動轉入已結標、催投（自動＋手動，含發送紀錄）、
  已結標詳細（全部具資格廠商的排名／同價標示／出價歷程）、決標 ／ 指定成交廠商 ／
  進入加價拍賣（預設全選、起標價＝前輪最高價）、已決標詳細（各輪紀錄）與「完成」
- **廠商管理**：新增（同時開通對外帳號）、編輯、停用／啟用、重設密碼

### 刻意做出來的限制（照規格）

- 截止前，列表與彈窗**一律不顯示出價金額**，只顯示家數與各家是否已出價
- 車輛資料與附件**排定拍賣前定版**，拍賣進行中一律唯讀、不可增刪附件
- 內部參考價（車両価格範囲・車両評価）標示為內部限定，對外站完全不呈現
- 車検証・自動車保険証券・運転免許証・個人資訊類附件不在資料裡，也不會出現在任何畫面

## 對外系統（廠商競價站）

**全新設計**、手機優先、全站日文（用 vue-i18n 架構但只有 `ja` 一份，不做語言切換）。

設計方向取自日本中古車拍賣的兩個實物：**出品票**（罫線密排的資料表）與**會場的締切看板**。

| | |
|---|---|
| 底色 | `#E9EDE8` 淡青灰（出品票紙色），卡片純白 |
| 主行動色 | `#0B4FA8` 深藍（比 portal 的 `#0568FF` 再沉一點，白底對比更好） |
| 強調色 | `#C8362B` 朱色 —— 只用在「快截止」與「落札」印章 |
| 數字字體 | Oswald（會場看板／發車標的窄體數字），**只用在數字**，日文一律用系統日文字體 |
| 標誌性元素 | 每張卡片照片下緣的**締切看板橫條**，顏色隨剩餘時間 深色 → 琥珀 → 朱色 |

### 涵蓋的功能

- **登入**：Email ＋ 密碼、不開放註冊、忘記密碼（寄送畫面）、停用廠商擋登入、未登入不揭露任何車輛資訊
- **出品一覧**：卡片列表、**預設剩餘時間最短優先**、篩選抽屜（メーカー／車種・年式・走行距離・色・入札状況）、**無限滾動**、empty component
- **車両詳細**：照片輪播（滑動、縮圖、全螢幕放大）、出品票式車輛資料表、備考、其他附件站內內嵌預覽、拍賣資訊與倒數、手機端 sticky 出價按鈕／PC 端右側固定面板
- **入札**：金額欄位（`inputmode="numeric"`、自動千分位）、下限提示、快速加算、**二次確認以大字顯示金額**、可調降但不得低於下限、可無限次修改
- **入札中／落札済み**：與列表共用卡片；落札済み 顯示成交金額與落札印章，且**沒有出價按鈕**
- **お知らせ**：未讀 badge、**點開即標記已讀**（沒有「全部已讀」也不能刪除）、五種通知（新出品／加價輪邀請／即將截止／落札／非落札）、關聯拍賣連結

### 刻意做出來的限制（照規格）

- 只看得到**自己本輪的出價**。看不到其他家金額、目前最高價、出價家數、自己是否領先
- 加價輪只有被勾選的廠商看得到；起標價（＝前輪最高價）明確顯示且必須高於它才能出價
- 已結標／已決標的拍賣不出現在出品一覧；未得標只透過通知告知
- 內部參考價、貸款餘額、借款人個資、個人資訊類附件一律不呈現

## 專案結構

```
demo/
├── index.html          入口頁（選擇要看哪一個 Demo）
├── internal.html       內部系統 entry
├── dealer.html         對外系統 entry
└── src/
    ├── shared/         兩站共用的「後端」
    │   ├── constants.js  車輛欄位定義（ja/zh 標籤、可編輯、對外可見）、附件白名單、狀態
    │   ├── seed.js       假資料
    │   ├── store.js      localStorage 持久化 + 跨分頁同步 + 伺服器時間（含 Demo 偏移）
    │   ├── engine.js     拍賣邏輯：排定／出價／結標／決標／指定成交／加價輪／催投／通知
    │   ├── photos.js     車輛照片（SVG data URI 產生，完全離線）
    │   └── format.js     金額千分位、日期、倒數
    ├── internal/       Vue 3 + Element Plus + vue-i18n(ja/zh)
    └── dealer/         Vue 3 ＋ 手寫 CSS + vue-i18n(ja)
```

依需求**沒有寫測試**。
