# 車輛拍賣平台 —— 純前端 Demo

零後端、假資料的可操作 Demo，用來展示抵押車輛線上拍賣平台的功能與拍賣機制。

## 快速開始

```bash
npm install
npm run dev
```

開站後在登入頁點任一帳號即可進入，不需密碼。

| 帳號 | 角色 | 用途 |
|---|---|---|
| 拍賣營運（田中 健一） | 公司人員 | 車庫與拍賣管理，可看底價與貸款餘額 |
| 山田商事 | 二手車商 | 主要示範視角，預設情境都以他為主 |
| 鈴木自動車 | 二手車商 | 用來演示競價、被超越與代理反超 |

## Demo 控制台

右下角的浮動控制台可以手動觸發任何狀態改變，不必等真實時間流逝。

- **快捷鍵**　`` ` `` 開合、`Esc` 收成精簡
- **三段收合**　圓鈕 → 窄橫條 → 完整面板；可切到四個角落，位置與模式都會記住
- **不影響瀏覽**　全程 `position: fixed` overlay，頁面 layout 寬度不會因開合而改變；點面板外也不會關閉，方便邊操作邊看頁面反應

功能區塊：

| 區塊 | 能做什麼 |
|---|---|
| 時間 | 快轉 1 分／10 分／1 小時／1 天；加速 1x／10x／60x／暫停；回到真實時間 |
| 模擬出價 | 以任一車商身分出價（含 4 家不可登入的），可連續隨機出價 |
| 強制狀態 | 立即開標／立即結標／強制流標／強制議價／強制撤標 |
| 推送通知 | 12 種通知類型任選，指定收件者立即送出 |
| 場景 | 一鍵切換角色、載入 6 組預設情境、重置為初始資料 |

**示範時建議直接用「場景」區的預設情境**，一鍵就是要展示的畫面：

- 即將結標的熱門車（剩 2 分鐘、8 次出價、你領先）
- 你被超越了（通知已在鈴鐺裡）
- 軟結標延長中（已延長 9 分鐘）
- 議價中（收到議價邀請）
- 密封投標開標前（3 家已投標、金額全部隱藏）
- 代理出價互頂（價格被自動推到其中一方上限）

## 拍賣機制

三種方式的行為差異：

| | 定時開標 | 即時同步拍 | 密封投標 |
|---|---|---|---|
| 看得到目前最高價 | ✅ | ✅ | ❌ 只看得到自己的 |
| 軟結標 | 前 3 分鐘 → 延 3 分鐘（上限 60 分） | 前 15 秒 → 延 15 秒 | 無 |
| 代理出價 | ✅ | ✅ | ❌ 只能投一次 |
| 立即成交價 | ❌ | ❌ | ✅ |

**出價級距**（日圓）：< 50 萬 → 5,000／50–200 萬 → 10,000／200 萬以上 → 50,000。每筆拍賣也可改為固定金額。

**結標判定**：最高價 ≥ 底價 → 成交；差距 < 10% → 議價中（24 小時，逾期依序問下一位）；否則流標。

**代理出價**只出「打敗目前最高價所需的最小金額」。勝者與成交價由 `(上限, 設定時間)` 決定——上限相同時較早設定者勝，不會因為級距的奇偶而改變結果。

## 機密資料的隔離

底價、貸款餘額、代理出價上限三項永不出現在車商可見的畫面。`src/architecture.test.ts` 在原始碼層面把這件事鎖住：車商頁面不得引用 `reservePrice` / `loanBalance` / `ReserveHint`，出價紀錄不得顯示 `maxAmount`。

撤標理由同樣只有公司人員看得到，車商端只顯示「已下架」。

## 資料

全部為假資料，狀態存在 localStorage。控制台的「重置為初始資料」可回到乾淨狀態。

初始資料：26 台車輛（12 台純在庫）、14 筆拍賣涵蓋三種方式與五種狀態、6 家車商、8 則歷史通知。`faker.seed(20260728)` 固定，重置後內容完全相同。

車輛照片來自 loremflickr；**無網路時自動改用本地產生的 SVG，不會出現破圖**。

## 架構

一個虛擬時鐘驅動一組純函式引擎，引擎回傳新資料與事件陣列，事件再轉成通知寫入 store。所有頁面只讀 store，不含任何狀態轉換邏輯。

```
虛擬時鐘 → 每 250ms tick → advanceAuctions(data, now) → { data, events }
                                                           ↓
                                             events → 通知 → toast / 鈴鐺
```

```
src/
  engine/    拍賣規則（純函式，不讀時間也不讀 store）
  clock/     虛擬時鐘（加速、暫停、快轉）
  store/     zustand + localStorage
  data/      假資料、車款清單、預設情境
  components/
  pages/
```

兩個刻意的設計決定：

- **倒數計時不寫回 store**：`<Countdown>` 用自己的 1 秒 interval，每秒重繪只影響那個元件，不會觸發 store 寫入。
- **`advanceAuctions` 沒有變化時回傳原本的物件參照**，所以 250ms 的迴圈在拍賣沒事發生時完全不造成重繪或 localStorage 寫入。

## 測試

439 個測試，分三層：

- **引擎**（TDD）：級距邊界、軟結標、代理互頂、結標三分支、議價輪替、冪等性
- **頁面**：以 Testing Library 掛起整個路由樹，驗證每個畫面的行為與底價隔離
- **架構守衛**：在原始碼層面鎖住機密資料隔離、引擎純度、控制台的 overlay 約束

## 已知限制

- shadcn 目前的預設 style（base-nova）底層是 **Base UI 而非 Radix**，所有 Trigger 用 `render={<Button/>}` 而不是 `asChild`。維護時要注意這與多數網路範例寫法不同。
- 視覺只做到規格定的色票與密度規範，沒有再跑一輪專門的視覺打磨。
