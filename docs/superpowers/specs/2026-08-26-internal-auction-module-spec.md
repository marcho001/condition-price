# 一、需求背景

車輛違約回收入庫後需要盡快去化。買方為 3–5 家長期合作的二手車廠商，廠商在出價前會親自看實車。銷售方式為密封投標：廠商在期限內各自出價，截止後由內部開標；不設底價。若內部認為價格偏低或出現同價，可發起加價輪再次徵求出價，輪數不限。

本期在既有內部 portal（xstar-web-pc）新增拍賣模組，涵蓋「收到車 → 排定拍賣 → 開標 → 決標／加價輪」。上游違約回收與下游收款、過戶、交車為線下流程。

廠商出價的對外站台另起專案，後端拍賣核心與資料共用。

# 二、名詞與規則定義

|名詞|定義|
|---|---|
|第一輪拍賣|由「排定拍賣」發起的首次投標。全體廠商可見，起標價 0 元|
|加價輪|前一輪結標後由內部發起的下一輪投標。僅被勾選的廠商可見並具出價資格|
|輪次|同一台車的第幾次投標。第一輪為第 1 輪，之後依序累加|
|起標價|該輪出價下限的基準。第一輪為 0 元；加價輪為前一輪的最高出價金額（前一輪無人出價時為 0 元）|
|結標|該輪拍賣截止時間到達，投標關閉|
|決標|內部指定得標廠商，該筆訂單進入「已決標」|
|有效出價|廠商在該輪內最後一次送出的金額|

## 2.1 出價與排名規則

|項目|規則|
|---|---|
|出價下限|第一輪：出價金額 ≥ 0 元。加價輪：出價金額**必須高於**該輪起標價|
|修改出價|截止前可修改，次數不限，以最後一次送出的金額為有效出價|
|排名|依該輪有效出價金額由高到低|
|同價|最高出價有兩家以上並列時，「決標」按鈕 disable。可透過「指定成交廠商」或「進入加價拍賣」處理|
|無人出價|該輪最高出價顯示為空，「決標」按鈕 disable。可透過「進入加價拍賣」重新徵求出價，起標價為 0 元|
|截止判定|以伺服器時間為準（日本時區），截止後送出的出價一律拒絕，不設寬限期、不做自動延長|
|幣別與格式|日幣，無金額上限，顯示千分位|

# 四、車輛管理

## 4.1 車輛進入列表的方式

```
收車人員確認收到車
        ↓
在 order 上一鍵呼叫 API 變更訂單狀態
        ↓
該訂單的車輛出現在「車輛管理」列表，狀態＝待排定拍賣
        ↓
車輛資料沿用該訂單進件時填寫的資料
```

|項目|說明|
|---|---|
|觸發來源|收車人員在 order 上的一鍵操作，透過 API 變更訂單狀態|
|資料來源|沿用進件時填寫的車輛資料，本模組不重新輸入|
|可編輯範圍|僅「會因使用時間而改變」的欄位可由內部更新為收車後現況（見 4.4.1）。其餘欄位唯讀|
|更新後的寫入位置|**不寫回 order**，另存於本模組的收車現況資料表（實作方式待確認，見 10.2）|
|訂單狀態值與取資料 API|待確認（見 10.1）|

## 4.2 列表欄位

|欄位|說明|
|---|---|
|orderNo|訂單編號|
|車牌|進件資料|
|廠牌／車型|進件資料|
|年份|進件資料|
|顏色|進件資料|
|收車日|訂單狀態變更為已收車的日期|
|狀態|待排定拍賣|
|操作|「車輛詳細」、「排定拍賣」|

列表**不顯示里程**（里程於「車輛詳細」彈窗中呈現與更新）。

分頁：需要（在架車輛預估不超過 100 台）。篩選、排序與分頁規則見 9.1。

## 4.3 車輛資料欄位

「收車後可編輯」＝該欄位會隨車輛被繼續使用而改變，開放內部人員在收車後更新為現況；其餘欄位一律唯讀，以進件資料為準。

### 4.3.1 走行距離

|項目|規則|
|---|---|
|進件資料|區間值（例：3 萬 ~ 5 萬 km），**不對外呈現**|
|本模組|收車後由內部在「車輛詳細」彈窗填寫**實際里程**（單一數值，km）|
|必填時機|**排定拍賣前必填**。未填寫時「排定拍賣」按鈕 disable|
|對外呈現|一律呈現實際里程|

### 4.3.2 車輛備註

進件資料之外，本模組新增一個**車輛備註**欄位，供內部補充進件欄位涵蓋不到的說明事項（例：收車時發現的碰撞痕、內裝狀況、鑰匙／備品缺件）。

|項目|規則|
|---|---|
|欄位|備註（自由文字，非必填）|
|填寫位置|「車輛詳細」彈窗|
|可編輯期間|僅「待排定拍賣」狀態可編輯，排定拍賣後唯讀（見 9.2）|
|寫入位置|**不寫回 order**，與收車現況資料一併存於本模組（見 10.2）|
|對外站|**呈現**於廠商端車輛詳細頁|
|留存|留存前後值、操作人、時間|

## 4.4 操作 —— 「車輛詳細」彈窗

> **背景**：進件資料與收車之間隔了一段違約處理期間，車輛在這段期間仍持續被使用。里程一定不會是進件當時的數字，車況與外觀也可能改變。因此本彈窗除了附件之外，必須完整列出車輛詳細資料，並開放內部人員將**會隨使用時間改變的欄位**更新為收車後的現況，作為對外拍賣的依據。

|區塊|內容|可編輯|
|---|---|---|
|標頭|orderNo、車牌（識別用）|—|
|車輛詳細資料|4.3 全部欄位|依 4.3 的「收車後可編輯」欄位；其餘唯讀|
|車輛備註|本模組新增的自由文字欄位（見 4.3.2）|可編輯|
|附件清單|列出該車目前的附件（範圍見 4.4.2），圖片可放大檢視、pdf 可預覽|—|
|上傳新附件|彈窗下方提供上傳功能，用途包含收車後的現況照片、內部人員線下向廠商取得的評分表|可上傳／刪除|

### 4.4.1 收車現況更新

|項目|規則|
|---|---|
|可編輯欄位|走行距離（實際里程）、次回車検日、自賠責保険の有効期限、車輛備註（見 4.3.2）|
|現況照片|進件時的車輛照片可能已與現況不符。收車後另行拍攝的照片一律以「上傳新附件」加入，**不覆蓋進件照片**|
|寫入位置|**不寫回 order**，另存於本模組的收車現況資料表。order 的進件資料維持原樣不受影響|
|讀取優先序|對外站與本模組顯示時，若該欄位有收車現況值則以現況值為準，否則回落至進件值|
|可編輯期間|僅在「待排定拍賣」狀態下可編輯。排定拍賣後一律唯讀（見 4.4.3）|
|留存|每次更新留存欄位、前後值、操作人、時間|
|實作方式|資料表結構與 API 待確認（見 10.2）|

### 4.4.2 附件範圍

**個人資訊類附件不出現在本模組的任何畫面**，也不對廠商公開。下表為本模組顯示且對外站呈現的**全部**附件類型；未列於表中者一律不顯示、不呈現。

|附件類型|
|---|
|車輛照片（進件上傳）|
|車両チェックシート（前／後／左／右）|
|走行距離メーター照片|
|1列目シート／2列目シート／エンジン写真等車輛部位照片|
|本模組上傳的附件（收車現況照片、評分表、其他）|

不顯示、不呈現的附件包含（但不限於）：車検証、自動車保険証券、運転免許証の写真、個人情報添付（身分証明書、収入証明書、社会保険証明書、源泉税証明書、銀行資金証明書、個人納税証明書、不動産証明書）。

> 車検証與自動車保険証券載有所有者・使用者的氏名與住所，屬借款人個資，本期一律不公開。

### 4.4.3 上傳規則

|項目|規則|
|---|---|
|支援格式|圖片（jpg / jpeg / png）、pdf|
|張數|不限，可多次上傳|
|單檔大小上限|依系統慣例|
|清單資訊|檔名、上傳人、上傳時間、預覽、刪除|
|對外可見性|依 4.4.2，不提供逐檔開關|
|可上傳期間|僅「待排定拍賣」狀態可上傳與刪除。**拍賣進行中不開放上傳新附件**；已結標、已決標一律唯讀（見 9.2）|

# 五、拍賣管理

## 5.1 三個 tab

|tab|內容|可見權限|
|---|---|---|
|拍賣進行中|投標期間內的拍賣，含第一輪與加價輪|拍賣營運、決標管理|
|已結標|已到截止日、尚未決標的拍賣|僅決標管理|
|已決標|已決標的訂單|僅決標管理|

## 5.2 拍賣進行中

### 5.2.1 列表欄位

|欄位|說明|
|---|---|
|orderNo|訂單編號|
|車輛資料|車牌、廠牌／車型、年份、里程、顏色|
|輪次|第 N 輪|
|起訖日期|拍賣開始日 ~ 結束日|
|剩餘時間|依伺服器時間倒數，倒數結束後自動轉入「已結標」|
|**已出價家數**|該輪已出價的廠商家數（不顯示金額）|
|操作|「車輛詳細」、「催投」|

截止前，列表與彈窗一律不顯示出價金額。

### 5.2.2 操作 —— 「車輛詳細」彈窗

內容同 4.4（車輛詳細資料 + 附件清單），另加該輪拍賣資訊：輪次、起訖日、剩餘時間、起標價、已出價家數、各廠商是否已出價（僅狀態，不含金額）。

**拍賣進行中為唯讀**：車輛詳細資料不可編輯、不可上傳新附件、不可刪除既有附件。理由是廠商已依現有資料出價，投標期間變動標的資料會影響出價基礎。

車輛詳細資料與附件（含線下向廠商取得的評分表）**於排定拍賣前完成收集**，排定拍賣後不再變動。

### 5.2.3 操作 —— 「催投」

對該輪尚未出價的廠商發出即將截止通知。

|項目|說明|
|---|---|
|對象|該輪具出價資格且尚未出價的廠商|
|觸發方式|**手動觸發 + 自動觸發**，兩者並行|
|自動觸發|該輪**結標日前 2 天的早上 09:00（JST）自動發送一次**。同一輪自動發送以 1 次為限|
|手動觸發|不限次數，內部可另行手動催投|
|拍賣期間過短|若排定當下已過或不足 2 天（例：起訖日僅 1 天），該輪不發自動催投，僅能手動觸發|
|對象重算|自動發送當下重新計算未出價名單，已出價的廠商不會收到|
|通知管道|Email + SMS + 對外站站內通知|
|模板|待定（見第六章）|

## 5.3 已結標

拍賣結束後，訂單自動由「拍賣進行中」轉移到「已結標」。

|欄位|說明|
|---|---|
|orderNo|訂單編號|
|車輛資料|車牌、廠牌／車型、年份、里程、顏色|
|輪次|第 N 輪|
|起訖日期|該輪起訖日|
|最高出價|該輪最高有效出價金額；無人出價時為空|
|結標日|該輪截止日|
|操作|「詳細」|

## 5.4 已結標 —— 「詳細」彈窗

列出所有廠商以及他們的出價。

|欄位|說明|
|---|---|
|名次|依金額由高到低|
|廠商名稱|該輪具出價資格的廠商全部列出|
|出價金額|該輪有效出價；未出價者顯示「未出價」|
|出價時間|最後一次送出的時間|
|同價標記|最高價並列時，於並列各列標示|

無人出價時，出價列表以 empty component 佔位。彈窗同時顯示車輛摘要、輪次、該輪起訖日、該輪起標價。

### 5.4.1 三個操作

|操作|行為|disable 條件|
|---|---|---|
|決標|決標給最高出價廠商，該訂單轉入「已決標」|① 無人出價<br>② 最高出價有兩家以上相同|
|**指定成交廠商**|由內部從**最高價並列的廠商**中選定一家成交，該訂單轉入「已決標」|最高出價未出現並列（含無人出價、僅一家最高價）|
|進入加價拍賣|開啟「加價拍賣設定」彈窗（見 5.5）|無|

「決標」與「指定成交廠商」皆需二次確認，顯示成交廠商與金額，成功後觸發得標／未得標通知。

### 5.4.2 「指定成交廠商」規則

|項目|規則|
|---|---|
|使用時機|**僅限最高出價同價時**。非同價情形一律走「決標」或「進入加價拍賣」|
|可選對象|**僅最高價並列的廠商**。未出價廠商、非最高價廠商皆不可被指定|
|成交金額|**等於該廠商的出價金額**，內部不可輸入或調整|
|指定理由|**不需填寫**|
|留存|選定廠商、金額、操作人、時間|

> 「指定成交廠商」為本版新增流程，用途單一：在同價僵局下直接擇一成交，作為「進入加價拍賣」之外的另一條出口。

## 5.5 「進入加價拍賣」彈窗

|欄位|必填|預設值|規則|
|---|---|---|---|
|拍賣開始日|是|今日|與 4.5 同規則|
|拍賣結束日|是|今日 + 7 日|與 4.5 同規則|
|廠商勾選|是（至少一家）|**全部勾選**|列出所有廠商。僅被勾選的廠商會收到加價拍賣通知並取得出價資格，未被勾選的廠商看不到此拍賣|

### 5.5.1 submit 後行為

|項目|內容|
|---|---|
|訂單流向|退回「拍賣進行中」tab|
|輪次|＋1|
|起標價|前一輪的最高出價金額；前一輪無人出價時為 0 元|
|出價限制|本輪出價必須高於起標價（起標價為 0 元時，出價 ≥ 0）|
|通知|對被勾選的廠商發出加價拍賣通知（模板待定）|
|前一輪資料|保留，不覆蓋。每輪各自留存起訖日、邀請名單、起標價、各家出價與時間|

### 5.5.2 加價輪可重複發起

輪數不限。每一輪結標後，都可在「已結標」的詳細彈窗中三選一：決標 / 指定成交廠商 / 再進入加價拍賣。

無人出價的拍賣同樣透過「進入加價拍賣」重新徵求出價，作為重新排定拍賣的方式。

## 5.6 已決標

|欄位|說明|
|---|---|
|orderNo|訂單編號|
|車輛資料|車牌、廠牌／車型、年份、里程、顏色|
|得標廠商|—|
|成交金額|—|
|決標輪次|第 N 輪|
|決標方式|決標 / 指定成交廠商|
|決標日期／操作人|稽核用|
|操作|「詳細」（唯讀，含各輪出價紀錄）、「完成」|

### 5.6.1 「完成」按鈕

付款與過戶為線下流程。線下完成後，由內部在此列表點「完成」（二次確認）標記該筆結案。系統不驗證款項與過戶狀態。

標記完成後：

|項目|行為|
|---|---|
|內部列表|該筆訂單**自「已決標」列表移除**。不新增第四個 tab、不提供「已完成」篩選條件|
|資料留存|資料不刪除，狀態標記為「已完成」，僅保留稽核紀錄（見第七章）|
|對外站|「已得標」列表不再顯示該筆|

## 5.7 狀態流轉

```
待排定拍賣 ──排定拍賣──▶ 投標中（第 1 輪）──截止──▶ 已結標
                                                     │
                          ┌──進入加價拍賣────────────┤
                          ▼                           ▼
                   投標中（第 N 輪）──截止──▶ 已結標 ──決標／指定成交廠商──▶ 已決標 ──完成──▶ 已完成
```

|狀態|所在位置|
|---|---|
|待排定拍賣|車輛管理|
|投標中|拍賣管理 → 拍賣進行中|
|已結標|拍賣管理 → 已結標|
|已決標|拍賣管理 → 已決標|
|已完成|不在任何列表呈現（見 5.6.1）|

# 八、廠商管理

拍賣廠商為獨立的一批主檔，於本模組建檔，**不沿用既有的販売業者主檔**。

## 8.1 欄位

|欄位|必填|說明|
|---|---|---|
|廠商名稱|是|—|
|聯絡人|是|—|
|電話|是|—|
|Email|是|通知寄送對象，同時作為對外站登入帳號|
|啟用／停用|是|預設啟用。停用後不再收到通知、不出現在加價輪勾選名單、無法登入對外站|
|備註|否|自由文字|

## 8.2 操作

|操作|說明|
|---|---|
|新增廠商|建立主檔並同步開通對外站帳號|
|編輯|修改上述欄位|
|停用／啟用|切換狀態；停用不刪除資料|
|重設密碼|重發對外站帳號密碼|

## 8.3 帳號規則

|項目|規則|
|---|---|
|對應關係|**一家廠商一個帳號**，不支援單一廠商多帳號|
|帳號識別|以 Email 作為登入帳號|
|開通時機|新增廠商時一併開通|

## 8.4 權限與核准

|項目|規則|
|---|---|
|維護權限|**拍賣營運與決標管理皆可完整操作**，不另設權限（見 3.2）|
|名單增減|**不需核准流程**，由具權限者直接新增或停用|

## 8.5 對進行中拍賣的影響

|情境|行為|
|---|---|
|拍賣進行中新增廠商|不追加至已開始的輪次，自下一輪起才具出價資格|
|拍賣進行中停用廠商|已送出的出價保留並列入排名；不再收到催投與後續通知|
