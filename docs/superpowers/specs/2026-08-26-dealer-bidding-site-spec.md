# 一、需求背景

車輛違約回收後採密封投標方式賣給 3–5 家長期合作的二手車廠商，廠商在出價前會親自看實車。本系統為廠商端站台，提供廠商查看邀標車輛、出價、修改出價，以及查看已得標車輛。

廠商以內部開通的帳號密碼登入，不開放註冊。

---

# 二、名詞與規則定義

|名詞|定義|
|---|---|
|第一輪拍賣|全體廠商可見，起標價 0 元|
|加價輪|僅被內部勾選的廠商可見並具出價資格。起標價＝前一輪的最高出價金額（前一輪無人出價時為 0 元）|
|有效出價|廠商在該輪內最後一次送出的金額|

|規則|說明|
|---|---|
|出價下限|第一輪：出價金額 ≥ 0 元。加價輪：出價金額必須高於該輪起標價|
|修改出價|截止前可修改，次數不限，**可調降**，但仍須符合上述出價下限。以最後一次送出的金額為有效出價|
|截止判定|以伺服器時間為準（日本時區），截止後送出一律拒絕，不設寬限期、不做自動延長。前端倒數以伺服器時間校正|
|同時多台|常態會有多台車同時在拍賣|
|幣別與格式|日幣，無金額上限，顯示千分位|

## 2.1 資訊揭露

|資訊|廠商是否可見|
|---|---|
|自己本輪的有效出價|可見|
|其他廠商的出價金額、廠商身分、邀請名單|不可見|
|本輪目前最高價、目前出價家數|不可見|
|自己是否為目前最高價|不可見|
|加價輪的起標價（＝前一輪最高出價）|可見|
|內部參考價、貸款餘額、借款人個資、個人資訊類附件|不可見|
|自己的歷史出價、過往拍賣紀錄|不呈現|
|自己得標車輛的成交金額|可見|

# 四、登入與密碼

## 4.1 登入

|項目|規則|
|---|---|
|入口|帳號 + 密碼|
|帳號來源|不開放註冊。由內部系統的帳號設定功能建立帳號後提供給廠商|
|帳號粒度|一家廠商一個帳號，多人共用（不做主／子帳號）|
|未登入|不揭露任何車輛資訊，一律導向登入頁|

## 4.2 重設密碼

|情境|流程|
|---|---|
|廠商自助（忘記密碼）|登入頁「忘記密碼」→ 輸入帳號／Email → **寄送 Email 重設連結** → 設定新密碼|
|內部代為重設|內部在 portal 重設，交付新密碼給廠商|
|登入後修改密碼|提供修改密碼入口|

重設連結有效期限、首次登入是否強制修改密碼，見 8.4。

# 五、拍賣列表

## 5.1 可見範圍

|類型|可見條件|
|---|---|
|第一輪拍賣|投標中的全部可見|
|加價輪拍賣|僅被內部勾選的廠商可見|

已結標、已決標的拍賣不出現在此列表。

## 5.2 卡片內容

以卡片列表呈現，點擊卡片進入車輛詳細頁。

|元素|說明|
|---|---|
|車輛照片|首張照片作為縮圖，無照片時顯示 placeholder|
|車輛簡要資訊|廠牌／車型、年份、里程、顏色|
|拍賣時間|起訖日 + 剩餘時間倒數|
|起標價|第一輪顯示 0 元；加價輪顯示起標價金額|
|我的出價狀態|「未出價」／「已出價：金額」（本輪）|
|輪次標記|加價輪的卡片加上標記|

## 5.3 篩選與排序

提供篩選功能協助廠商快速找到標的，條件清單與預設排序見 8.1。手機端篩選收在「篩選」按鈕後的抽屜（drawer）中。

## 5.4 空狀態

無可出價的拍賣時，顯示 empty component。

# 六、車輛詳細頁與出價

## 6.1 詳細頁內容

|區塊|內容|
|---|---|
|照片|車輛照片、車輛檢查表（前／後／左／右）、走行距離メーター等車輛部位照片，可滑動／放大檢視|
|車輛完整資料|沿用內部系統的車輛資料欄位（欄位與日文標籤見內部系統文件 4.3）。內部參考價（車両価格範囲、車両評価）不呈現|
|其他附件|內部上傳的車輛相關附件，含線下取得的評分表。圖片與 pdf 皆採**站內內嵌預覽**。附件範圍見內部系統文件 4.4.1（個人資訊類附件一律不呈現）|
|備註|內部填寫的說明事項（若有）|
|拍賣資訊|輪次類型、起訖日、剩餘時間倒數、起標價|
|我的出價|本輪已出價時，顯示金額與出價時間|
|出價按鈕|主要按鈕，手機端固定於畫面底部（sticky）|

## 6.2 出價流程

```
點「出價」→ 輸入金額 → 點「確認」→ 二次金額確認 → 確認 → 出價成功
```

|步驟|內容|
|---|---|
|金額輸入|單一金額欄位，顯示該輪起標價與下限提示|
|校驗|① 必填、僅數字、正整數<br>② 符合該輪出價下限（見第二章）<br>③ 拍賣須在進行中<br>④ 廠商須具備該輪出價資格|
|二次確認|彈窗以大字顯示金額，提供「返回修改」與「確認出價」|
|成功|回到詳細頁，按鈕變為「修改出價」，顯示目前出價金額|
|失敗|依原因提示（未達下限／已截止／無資格／網路異常）|

## 6.3 修改出價

|項目|規則|
|---|---|
|入口|已出價的拍賣，按鈕文字為「修改出價」|
|預帶值|帶入本輪目前的出價金額|
|校驗|同 6.2，可調降但不得低於該輪出價下限|
|次數|截止前不限次數|
|二次確認|同 6.2|

## 6.4 加價輪的差異

|項目|說明|
|---|---|
|可見性|僅被內部勾選的廠商可見|
|起標價|＝前一輪的最高出價金額，明確顯示於詳細頁|
|出價下限|必須高於起標價|
|第一輪未出價的廠商|若被勾選，仍可在加價輪出價|

# 七、我的拍賣 / 已得標

## 7.1 我的拍賣

|項目|說明|
|---|---|
|內容|列出該廠商有出價的進行中標的|
|版型|與拍賣列表共用卡片元件|
|差異|卡片顯示「我的出價：金額」；進入詳細頁後按鈕為「修改出價」|
|移除時機|該輪結標後從此列表移除|

## 7.2 已得標

|項目|說明|
|---|---|
|內容|列出該廠商已得標的拍賣|
|版型|與拍賣列表共用卡片元件|
|卡片內容|車輛照片、車輛簡要資訊、成交金額、得標日期|
|詳細頁|車輛完整資料、附件、成交金額，無出價按鈕|
|移除時機|付款與過戶為線下流程，內部在 portal 點「完成」後，此列表不再顯示該筆|

未得標的拍賣不在站上呈現，以通知告知（見 8.2 表格第 5 項）。

# 八、通知

## 8.1 通知中心

|項目|說明|
|---|---|
|入口|導覽列「通知」|
|內容|通知標題、內文、時間、關聯拍賣連結|
|已讀狀態|需要（未讀數呈現方式見 9.3）|
|排序|時間新到舊|

## 8.2 通知事件

管道：**Email + 站內通知中心**。訊息模板文案待定，實作前需補齊。

|# |事件|收件對象|模板|
|---|---|---|---|
|1|新的拍賣（第一輪已排定）|全體廠商|待定|
|2|加價拍賣邀請|被內部勾選的廠商|待定（可帶入車輛資訊、本輪起標價、本輪截止日、拍賣連結）|
|3|即將截止|**僅該輪尚未出價的廠商**|待定|
|4|得標|得標廠商|待定|
|5|未得標|該輪其他具出價資格的廠商|不含金額與名次。例：「order:xxxx 抱歉您未得標」|
