## 2. 拍賣商與 xstar 差異



| | 日本車拍 | 我們 |
|---|---|---|
| 車是誰的 | **車商的**，拍賣場只是中間人 | **我們自己的**（回收車） |
| 拍賣場賺什麼 | 手續費，成交就有收入 | 車的成交價本身 |
| 對成交價的立場 | **中立**——賣多少錢跟拍賣場關係不大 | **不中立**——我們要成交價越高越好 |
| 底價誰訂 | 委託的車商訂 | 我們自己訂，而且牽涉貸款餘額 |
| 車況誰檢查 | 拍賣場的檢查員或第三方機構（跟買賣雙方沒有利害關係） | **我們自己的登錄人員** |

三件無法參考的事：

**（1）車況檢查的公信力較弱**

日本車拍的檢查員是中立第三方，車商相信評級。我們是賣家自己評自己的車，車商一開始可能會保守看待。這不是系統功能能解決的，要靠制度（標準化表單、訓練、申訴機制）慢慢建立。

**（2）底價的性質不同**

拍賣商的底價是車商的「我最少要賣多少」，純商業判斷。我們的底價需考慮貸款未償餘額，牽涉帳務認列與核准層級。

**（3）手續費模式**

拍賣商收手續費是因為提供了仲介服務。我們自己就是賣家，

## 3. 車況評級

| | 內容 |
|---|---|
| **日本同業** | 全業界共用同一套刻度：S / 6 / 5 / 4.5 / 4 / 3.5 / 3…，**R = 有修復歷，RA = 輕度修復，X = 極舊年式**，內裝另評 A–D。市場上把「4.5 分以上」當作優良車的分水嶺 |
| **判讀** | 我們沿用的是**日本車拍的現成通用語言，不是自創**。亞洲的二手車商看到「4.5 點」不需要任何說明就知道是什麼車況 |


- 日本的 **S 級有明確客觀門檻**（里程 1 萬公里以內、初次登記 12 個月內），不是靠感覺給的。我們訂評級標準時，越能寫成「可查證的條件」，登錄人員之間的落差就越小。

## 4. 誰來檢查車況 —— 我們跟同業最大的落差

| | 內容 |
|---|---|
| **我們的做法** | 內部登錄人員填標準化表單並評級，Phase 1 不導入第三方檢驗 |
| **USS / TAA / JU / ARAI** | **會場自己的檢查員**檢查。關鍵在於檢查員跟賣方、買方都沒有利害關係，車商因此信任評級 |
| **Aucnet** | 委託第三方檢查機構 **AIS**。AIS 一年檢查約 100 萬台，最多檢查 324 個項目，給 10 級評分。Aucnet 的線上交易就是建立在這份報告上 |
| **判讀** | 同業的評級之所以有價值，**不是因為表單設計得好，是因為評的人是中立的**。我們是賣家自己評自己的車，這一點車商一定會納入考量 |

Phase 1 不導入第三方檢驗是合理的（成本高、上線慢），但要清楚知道代價：

| 代價 | 說明 |
|---|---|
| 出價會偏保守 | 車商無法完全相信賣方自評的車況，會把不確定性反映在價格上 |
| 爭議率較高 | 評級跟實車不符時，我們既是賣方又是評級者，很難自證 |
| 難以說服新車商 | 沒往來過的車商，第一次出價會特別謹慎 |

**三個相對低成本的補強做法**（都在既有範圍內，不需要外部機構）：

1. **照片與資料的完整度直接拿來當信任替代品**——Phase 1 已規劃至少 20 張照片、傷痕圖、引擎聲音影片，這是我們目前最有效的手段
2. **明確的申訴機制**（見第 9 章）——「評錯了我認」比「我保證評得準」更能建立信任
3. **評級一致性追蹤**——記錄每位登錄人員的評級與後續申訴率，內部就能發現誰評得太寬鬆

> 這是我們相對同業最弱的一環，而且不是系統做得好就能解決的。Phase 1 靠資料完整度與申訴機制補，中期建議評估導入第三方檢驗。

## 5. 拍賣怎麼跑

| | 內容 |
|---|---|
| **我們的做法** | 定時開標，掛 3–7 天，期間隨時可出價；另有密封投標 |
| **日本同業** | **現場競價（セリ）為主，一台車只跑幾十秒**。價格從起標價自動往上跑，想要的車商就按鈕跟價。USS 東京會場有 16 條線同時進行，一天跑掉數千台 |
| **判讀** | 我們跟他們的節奏完全不同，而且**是刻意的** |

為什麼不學現場拍：

| 現場競價的前提 | 我們符合嗎 |
|---|---|
| 每場要湊到足夠的車量（一場數千台） | **不符合**——回收車是陸續進來的，不是成批到貨 |
| 車商願意固定時間到場或盯盤 | **不符合**——初期車商數量有限，難以要求 |
| 需要實體場地、拍賣師、現場作業人力 | **不符合**——Phase 1 沒有這個投入 |

**Aucnet 的存在證明不需要現場也能做**：它不把車集中到會場，車留在賣方手上，車商依檢查報告在線上出價。我們的模式跟它同一條路。

代價是：現場競價那種「一群人在同一個房間裡搶同一台車」的熱度，我們沒有。**這代表我們的成交價更依賴車商參與量**——這也是 Phase 1 文件第 6.11 節提到「要不要開放外部寄售」值得提早討論的原因。

## 6. 底價

| | 內容 |
|---|---|
| **我們的做法** | 營運人員設底價，車商完全看不到金額，只看得到「已達底價／尚差多少」；底價的修改與查看都留紀錄 |
| **日本同業** | 概念相同，稱為「**売り切り価格**」（賣斷價），由委託出品的車商設定，拍賣場負責執行，**不對競標者公開** |
| **判讀** | 「底價不公開」是全球車拍的共同做法，我們沒有特別之處。**真正不同的是底價怎麼算出來** |

同業的底價是單純的商業判斷（我這台車最少要賣多少）。我們的底價則同時牽涉：

- 貸款未償餘額
- 帳面差額的認列與核准層級
- 車輛繼續持有的保管成本

**這一塊沒有同業經驗可以參考，必須由財務與風控單位決定**——就是 Phase 1 文件第 6.1 節列的那些問題。

日本同業有一項做法值得學：**價格資訊高度透明給賣方**。日本車商在設定売り切り価格前，可以查到同款車近期的成交行情（CIS 等行情系統）。對應到我們，就是 Phase 1 已規劃的「底價設定畫面直接顯示參考資訊」——貸款餘額、市場估值、同款車過去成交價、已累積的保管成本。**這件事同業視為理所當然，我們也應該從第一天就做。**

> **給主管的一句話**：底價保密是業界標準；但底價怎麼訂，同業幫不上忙，要靠我們自己的財務政策。

## 7. 競價的三個機制

### 7.1 加價單位

| | 內容 |
|---|---|
| **我們的做法** | 依價格分級：50 萬以下加 5,000／50–200 萬加 10,000／200 萬以上加 50,000 |
| **日本同業** | 現場競價由系統自動往上跑，車商只決定「跟不跟」，不自己輸入金額 |
| **判讀** | 機制不同但目的一致：**都是不讓車商用極小金額慢慢磨** |

日本的做法比我們更徹底——車商連金額都不用想，只按「要／不要」。我們是線上長天期，做不到那樣，但這提醒我們一件事：**加價單位如果訂太細，車商的操作成本會變高、參與意願會下降**。這組數字上線後要依實際成交價分布回頭調。

### 7.2 匿名出價

| | 內容 |
|---|---|
| **我們的做法** | 出價紀錄只顯示「出價者 A / B / C」，不顯示車行名稱 |
| **日本同業** | 現場會場的性質決定了匿名性有限——人都在同一個場地裡。**線上與密封形式才有真正的匿名**。（各家的匿名規則未見公開說明，此處不做推測） |
| **判讀** | 我們的匿名設計**比同業更嚴格，而且應該更嚴格** |

原因是規模：日本一個會場一天上千台、幾千家車商，串通的協調成本很高、效果很低。**我們初期車商數量有限，串通反而容易**。匿名的成本極低，是這個階段性價比最高的防護。

### 7.3 自動延長（軟結標）

| | 內容 |
|---|---|
| **我們的做法** | 結標前 3 分鐘有人出價 → 結標時間延後 3 分鐘 |
| **日本同業** | 現場競價沒有「最後一秒出價」的問題——拍賣師會等到沒人跟價才落槌，本質上就是軟結標。**業者線上車拍的延長秒數未見公開資料** |
| **一般線上拍賣** | Yahoo!拍賣、モバオク、メルカリ 等日本主流線上拍賣，通行做法是**最後 5 分鐘內有出價就延長 5 分鐘**，可無限次重複 |
| **判讀** | 軟結標是線上拍賣的**標準配備，不是我們發明的規則**；只有秒數需要調整 |

我們用 3 分鐘、日本主流用 5 分鐘。3 分鐘的好處是結標時間比較收斂，壞處是車商反應時間短——**如果我們的車商多半用手機、且不會全程盯盤，5 分鐘可能比較安全**。這一項建議列入上線後觀察調整。

> 唯一我們比同業做得更嚴的是匿名，因為我們規模小、更需要防串通。

## 8. 流標之後 —— 議價

| | 內容 |
|---|---|
| **我們的做法** | 最高出價差底價 10% 以內 → 進入議價，系統通知最高出價者「加到底價就成交，給你 24 小時」；放棄則依序問第二、第三高 |
| **日本同業** | 業界有成熟的制度叫「**後商談**」：流標後由出品的車商提出一個「商談開始金額」，有意願的車商申請商談，雙方來回議價。**不少車輛是在後商談階段才成交的**，車商甚至會把後商談納入投標策略 |
| **判讀** | 議價不是我們的變通做法，是**日本車拍的標準環節**。我們做的是它的簡化版 |

我們刻意簡化的兩點，以及原因：

| 日本後商談 | 我們的做法 | 為什麼 |
|---|---|---|
| 雙方來回議價 | **系統直接開出底價，不開放喊價** | 避免車商學會「先出低價、等被邀請議價」 |
| 賣方自訂商談開始金額 | **限定差距 10% 以內才啟動** | 同上，把議價的可預期性壓到最低 |

**日本業界普遍採用後商談這件事本身，就是這個機制值得做的最強佐證**——它明顯提升成交率、縮短在庫時間。我們的簡化版比較保守，但方向一致。

> 議價（商談）是日本車拍的標準功能，不是我們發明的補救措施。我們只是把它做得更保守。

## 9. 爭議與申訴

| | 內容 |
|---|---|
| **我們的做法** |  |
| **日本同業** | **申訴期一般約 5–6 天，而且從「得標當下」起算，不是從交車起算**。里程篡改另有 6 個月的特別申訴期。金額不大的一般故障（數萬日圓內可修復）通常不受理 |


日本同業的規則有三個設計值得參考：

1. **申訴期短且從得標起算** —— 不給車商拖延空間，車輛狀態越早確認越好舉證
2. **設金額門檻** —— 小額瑕疵不受理，避免爭議處理成本吃掉毛利
3. **重大事項另設長期限** —— 里程篡改給 6 個月，因為這類問題不可能在幾天內發現

對我們的具體建議：

- 申訴期**從交車起算**（我們的車商不一定當天牽車），但天數可以縮短到 7 天
- **明訂金額門檻**（例如修復費用低於某金額不受理），這一項 Phase 1 文件目前沒有，建議補上
- **里程、事故、泡水等重大揭露不實，比照日本給較長期限**，不受一般申訴期限制

## 10. 收費與車商准入

這一章直接對應 Phase 1 文件第 6.7、6.11 節的待確認事項。

### 10.1 手續費

| | 內容                                                                                                                                                   |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| **我們的規劃** | 無手續費                                                                                                                                               |
| **日本同業** | USS 的模式是**買賣雙方都收**：出品方平均約 1.5%，一筆成交合計約 3%。另有固定式的成交費（每台約 1.0–2.5 萬日圓）與保管、搬出、系統費（數千至 1 萬日圓） |
| **判讀** | **這是同業的主要收入來源，但我們的處境不同**（見第 2 章）                                                                                              |


### 10.2 保證金與入會審查

| | 內容 |
|---|---|
| **我們的規劃** | 待確認，傾向信用額度制（繳保證金取得數倍出價額度） |
| **日本同業** | **入會門檻明確且不低**：需要古物商許可、書面資格審查（CAA 約 2–3 週）、通過後繳入會金與保證金。ARAI 是**依使用的每個會場分別繳保證金** |
| **判讀** | 保證金在日本車拍是**理所當然的行規，不是額外要求** |

這代表兩件事：

1. **車商對「要繳保證金才能出價」有既有認知**，我們要求保證金不會被視為刁難
2. **審查要花時間是常態**——同業要 2–3 週。我們的車商上線流程可以據此設定合理期望

我們規劃的信用額度制（保證金 50 萬 → 出價額度 500 萬）在日本並非通行做法，但邏輯一致，且對車商的資金壓力更小。**建議保留，並在跟車商訪談時直接驗證接受度**（第 6.8 節已列此題）。

> 保證金是業界行規、車商也習慣。

## 12. 這份文件回答了哪些待確認事項

對照 Phase 1 文件第 6 章：

| 待確認事項 | 同業經驗能幫上什麼 |
|---|---|
| 6.4 車況檢查做到什麼程度 | **幫得上**：同業靠中立第三方建立公信力，我們沒有。第 4 章提出三項補強 |
| 6.7 保證金要不要收 | **幫得上**：日本車拍一律收，是行規，車商有既有認知 |
| 6.9 申訴期訂多久 | **幫得上**：業界約 5–6 天、里程篡改 6 個月、小額不受理。建議補「金額門檻」 |
| 6.11 要不要收手續費 | **幫得上（但答案是相反的）**：同業收是因為他們是仲介；我們是車主，建議先不收 |
| 6.11 要不要開放外部寄售 | **幫得上**：同業的競價熱度來自車量規模，這題值得提早討論 |
| 6.1 底價與帳務結算 | **幫不上**：同業的底價是純商業判斷，不涉及貸款餘額。**必須由財務與風控決定** |
| 6.2 車輛庫存與保管 | **幫不上**：這是我們的內部流程 |
| 6.3 借款人清償／贖回 | **幫不上**：同業沒有這個問題 |
| 6.5 過戶與交車 | **幫不上**：取決於首發市場的法規 |
| 6.6 稅務與發票 | **幫不上**：同上 |

**簡單說：「拍賣怎麼跑」這一塊，同業經驗基本上都能佐證；「車為什麼會到我們手上」這一塊，只能靠我們自己。**
